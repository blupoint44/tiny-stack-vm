# Tiny Stack VM

A small interpreter for make.fun's tiny stack ISA: 32-bit wrapping arithmetic, a 256-value data stack, a 64-deep call stack, 256 words of memory, input/output, and the ISA's ten traps with their exact exit codes. One run answers all 40 instances deterministically.
